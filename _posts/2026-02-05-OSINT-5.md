## 1. How to Make a Sock Puppet?

나의 신원이 특정당하지 않게, 가짜 신원을 만들어야 할 때가 있다. 주로 다음의 순서를 따른다.

1. Use a virtual machine / different browser
2. Create an identity
3. Create a Fastmail email
4. Get a burner number
5. Use a Library/Cafe Wi-Fi
6. Create a Facebook/Instagram/X accounts
7. Keep the account active
8. Log in at least twice a week
9. Two Factor Authentication(2FA)

### a. Fake ID Generater
[Fake ID Generater](https://www.fakenamegenerator.com/)은 국가별 가짜 신원을 만들어주는 사이트다. 일반적으로 Target의 특성에 맞춰 국적 등의 설정을 한다.

### b. Profile Image

- [This Person Does Not Exist](https://thispersondoesnotexist.com/)는 AI로 생성된 가짜 인물 사진을 만들어준다.
- [Pixabay](https://pixabay.com/), [Pexels](https://www.pexels.com/)는 무료 이미지 사이트로, 이 사이트들에서 이미지를 골라볼 수도 있다.


> **Data Leak과 Data Breach의 차이
**Data Leak:** 의도하지 않은 민감 정보의 노출
**Data Breach:** 의도적이고 비인가된 접근

Database에서 특정인을 검색하기 위해 필요한 가장 좋은 정보는 **E-Mail, Phone Number**이지만, 이 외 추가적으로 **First and Last Name, Physical Address, Country, City, Age, Gender**가 있으면 좋다.

## 2. Finding Breach/Leak Databases
### a. Have I been pwned? / HIBP
[HIBP](https://haveibeenpwned.com/)는 내 데이터가 온라인상에 유출되어있는지 알 수 있는 사이트다.

> 실무에서는 다음의 내용을 확인하는 데 사용한다.
1. email이 valid한지
2. 대상의 관심사 확인
3. 어떤 타입의 data가 유출되었는지 확인

### b. DeHashed
[DeHashed](https://dehashed.com/)는 data breaches/leaks용 search engine이다. 구독해야 사용이 가능하다.

### c. IP Lookup
[IP Lookup](https://whatismyipaddress.com/ip-lookup)은 IP주소를 통해 디테일한 정보를 얻을 수 있는 사이트다. 유출 데이터에서 확인한 IP주소를 통해 추가적인 정보 수집이 가능하다.

### d. IntelligenceX
[IntelligenceX](https://intelx.io/)는 아카이브 된 웹사이트와 breached/leaked database를 검색할 수 있는 search engine이다. 부분적으로 무료다.

## 3. Downloading Leak/Breach Databases
Facebook, Twitter, Linkedin, Snapchat... 많은 Data Breach들이 존재한다. 다운받을 때는 Virtual Machine를 이용해 다운로드받는 게 좋다.
두 가지의 SW가 필요한데,

### 1. Torrent
파일을 다운로드 받을 수 있다. `magnet`은 torrent를 통해 다운받을 수 있는 링크의 format이다. 데이터 검색 시 참고하자.

### 2. Agent Ransack
Leaked Database의 데이터 검색을 가능하게 한다.

검색을 원하는 파일들이 담긴 폴더에서 Agent Ransack을 실행할 수 있다. `Containing text:`에 원하는 값을 입력하기만 하면 된다.

다음은 search에 필요한 몇 가지 팁들이다.
- Linkedin의 Member ID 검색: `View Page Source` →  `Ctrl`+`F` → Search `member:`
- 때로는 `Forgot Account?`를 활용하는 것도 방법이다.

## 3. How to search Leaked Databases?
인터넷으로 접근 가능한 Database들은 어떻게 찾을 수 있을까?

### 1. Google Search
검색어는 간단하다.
`"[사이트].com.7z" "leak" "download" "magnet:?"`

### 2. Size of.cat
[Size of.cat](https://archive.md/rNWZE)에서 다수의 leaked/breached database들을 찾아볼 수 있다.

## 4. So...
그래서 Target에 대한 정보를 수집하는 방법은...

1. Gather Target Info: Target의 SNS 계정 등을 우선 확보한다.
2. Verify Downloading Databases Legality: 나의 국가에서 Leaked/Breached Database를 다운로드받거나 소지하는 게 합법적인지 확인한다.
3. Check Email in Leaked Databases: haveibeenpwned에서 email과 전화번호를 검색해보고 online상에 유출되어 있는지 확인한다.
4. Use Online Services: 유출되어 있다면 온라인 서비스를 활용하거나,
5. Download and Search Locally: 직접 다운로드받아서 활용할 수 있다.

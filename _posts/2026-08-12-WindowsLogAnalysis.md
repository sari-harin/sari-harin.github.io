알고 있는 내용을 복습할 겸, 로그 분석에 관해 간단한 내용부터 기록하고 정리해보기로 했다. 이 글 카테고리의 목적이라고 할 수 있다.

## 0. 목표
1. Windows에서 로그인 성공/실패 시 어떤 Security Event가 발생하는가?
2. 해당 이벤트에서 사용자, 로그인 방식, 출발지, 실패 원인을 어떻게 읽을 수 있는가?
3. 정상적인 로그인과 공격 가능성이 있는 로그는 어떤 차이가 있는가?
4. 분석가로서 해당 Alert를 받은 뒤 무엇을 추가 조사해야 하는가?

## 1. 배경 지식
Windows의 이벤트에 대해 알아보자. 기본적으로는 다음 이벤트가 있다.
| Event ID | 의미 |
| -------- | ---------------: |
| **4624** | 계정 로그인 성공 |
| **4625** | 계정 로그인 실패 |
| 4634 | 로그온 세션 종료 |
| 4647 | 사용자가 명시적으로 로그오프 |
